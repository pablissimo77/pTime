## pTime 1.0.0

Initial public release of pTime.

### Features

- Project-based time tracking.
- Projects can be marked active or inactive.
- Project and statistics views can be filtered to active projects.
- Switching between projects and `PAUSE` mode.
- Daily and monthly statistics.
- Statistics reports show the period, project, and duration.
- Monthly reports are broken down by day and project.
- Statistics can be filtered to one project or all projects.
- Reports can be copied as tab-separated text to the clipboard for pasting into Excel or another spreadsheet application.
- Project list and application settings stored in SQLite.
- Only one pTime instance can run at a time, preventing concurrent access to the SQLite database.
- Database operations are centralized in a dedicated database module.
- Deleting a project requires confirmation and removes its time history; the
  running project is switched to `PAUSE` first.
- Portable Windows x64 and Linux x86_64 distributions.
- Version displayed in the About window.

### Downloads

- `pTime-1.0.0-windows-x64.zip` — portable Windows x64 version.
- `pTime-1.0.0-linux-x86_64.AppImage` — portable Linux desktop version.
- `pTime-1.0.0-linux-x86_64.AppImage.zsync` — update metadata for AppImage tools.
- `pTime-1.0.0-linux-x86_64.tar.gz` — Linux x86_64 archive.

### Usage notes

The Windows ZIP and Linux archive store `ptime.sqlite3` next to the
executable. The AppImage stores its writable runtime copy and database under
`~/.local/share/pTime` by default.
