# pTime

`pTime` — portable desktop-застосунок для обліку часу за проєктами. Програма написана на Object Pascal з використанням Lazarus/Free Pascal.

## Можливості

- створення списку проєктів;
- запуск відліку часу для вибраного проєкту;
- перемикання між проєктами та режим `PAUSE`;
- відображення поточного проєкту й тривалості роботи у плаваючій панелі;
- статистика за день і місяць;
- сортування статистики за назвою проєкту або тривалістю;
- копіювання статистики у Clipboard;
- налаштування шрифту, кольорів, розміру та позиції панелі.

Програма не потребує інсталятора, реєстру Windows або окремого сервера бази даних. Усі необхідні файли розміщуються поруч із виконуваним файлом.

## Технології

- мова: **Object Pascal**;
- IDE та framework: **Lazarus LCL**;
- компілятор: **Free Pascal Compiler**;
- графічний інтерфейс: Lazarus Component Library;
- база даних: **SQLite** через `SQLite3Conn` і `SQLDB`;
- форми: Lazarus `.lfm`;
- підтримувана архітектура: **64-bit**.

Залежності проєкту перелічені у `ptime.lpi`: `FCL`, `LCL`, `SQLDBLaz`, `DateTimeCtrls`.

## Підтримувані платформи

### Linux x86_64

У каталозі програми має бути:

```text
ptime
libsqlite3.so
```

Linux-збірка перевірена компіляцією у Lazarus/FPC.

### Windows x64

У каталозі програми має бути:

```text
ptime.exe
sqlite3.dll
```

Потрібна саме 64-bit DLL SQLite. 32-bit Windows не підтримується.

Офіційне джерело SQLite: [SQLite Download Page](https://www.sqlite.org/download.html). Потрібен пакет `sqlite-dll-win-x64-*.zip` із розділу **Precompiled Binaries for Windows**. Пакети `sqlite-dll-win-x86` та `sqlite-tools-win-x64` для цього застосунку не потрібні.

## Рекомендована структура portable-дистрибутива

Для Windows x64:

```text
pTime/
├── ptime.exe
├── sqlite3.dll
└── ptime.sqlite3       (створюється автоматично, якщо відсутній)
```

Для Linux x86_64:

```text
pTime/
├── ptime
├── libsqlite3.so
└── ptime.sqlite3       (створюється автоматично, якщо відсутній)
```

Бібліотека SQLite завантажується з каталогу програми. Її не потрібно копіювати у `System32`, додавати до системного `PATH` або встановлювати окремо.

Оскільки версія portable, база також зберігається поруч із програмою. Каталог має бути доступним для запису.

## Основні модулі

`ptime.lpr` — точка входу та створення форм.

`unit_info.pas` — головна інформаційна панель:

- показує поточний проєкт і час;
- оновлюється таймером щосекунди;
- має контекстне меню;
- дозволяє переміщувати панель мишкою;
- перемикає проєкти;
- записує часові інтервали у SQLite;
- створює необхідні таблиці бази даних.

`unit_options.pas` — вікно налаштувань:

- керування списком проєктів;
- налаштування зовнішнього вигляду та положення панелі;
- денна й місячна статистика;
- копіювання статистики у Clipboard.

`unit_about.pas` — діалог «About» із контактною email-адресою автора.

## Зберігання даних

Основна база — `ptime.sqlite3`.

Таблиця `timing` зберігає:

- назву проєкту;
- дату;
- час початку;
- час завершення;
- тривалість у секундах.

Також база містить:

- `projects` — список проєктів і порядок їх відображення;
- `settings` — шрифт, кольори, розмір і позицію інформаційної панелі.

Нові записи часу, список проєктів і налаштування зберігаються лише у SQLite. Файли `projects`, `option` та текстові журнали за датами програмою не використовуються і не створюються.

Місячна статистика фільтрується одночасно за роком і місяцем, тому дані однакових місяців різних років не змішуються.

## Важливі особливості

- панель працює поверх інших вікон (`fsSystemStayOnTop`);
- підтримка системного трею передбачалась, але відповідний код зараз закоментований;
- база та налаштування зберігаються у каталозі portable-дистрибутива;
- для Windows використовується `sqlite3.dll`, для Linux — `libsqlite3.so`;
- 32-bit збірки не плануються.
